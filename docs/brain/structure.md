# Brain repository structure

> Snapshot 2026-10-11 (`78261d6`): 102 corpus docs, 11 branches, 41 catalogued sources. Re-count before quoting these numbers. The validator prints them.

## Top level

| Path | Role | Edited by hand? |
|---|---|---|
| `README.md` | Entry point: scope, platform lookup tables, start-here routing, quality contract, known conflicts. The validator checks its platform table against the canonical doc. | Yes |
| `corpus/` | The authored knowledge (Markdown) | Yes |
| `corpus-manifest.json` | Schema 3: anchors, supported majors, collection → directories, logical KB names | Yes, carefully |
| `sources/source-catalog.md` | Every `source://` ID with title, version, type, use, applicability, authority, gaps | Yes |
| `feature_catalog.json` | Protection families + aliases for server.py routing | **No.** Generated by `build_feature_catalog.py` |
| `feature-alias-overrides.json` | Hand-curated aliases merged into the feature catalog | Yes |
| `docs/authoring-guide.md` | Writing rules, header schema, review states | Yes |
| `docs/kb-integration.md` | Collections, metadata contract, retrieval and smoke criteria, approval boundary | Yes |
| `scripts/` | Validate / build / plan / re-ground / reconcile / feature catalog (see [pipeline](pipeline.md)) | Yes |
| `semantic-review/` | Historical review reports (2026-08-20) | Rarely |
| `build/` | Generated chunks. **Git-ignored. Never commit.** | No |

## Document header and IDs

Every corpus file starts with a scalar header (full rules: [authoring instructions](../../.github/instructions/brain-corpus-authoring.instructions.md)):

```text
Document ID: DP-QA-PROD-018
Product: Radware DefensePro
Applicability: Release inventory for DefensePro 8.x and 10.x
Applicability scope: cross-family
Product line: DefensePro 8 and DefensePro X
Compared software versions: 8.35.5.0, 10.13.0.1
Authority: Exact-version Release Notes and User Guides in the indexed corpora
Status: reviewed
Owner: Guy Perez
Last reviewed: 2026-10-08

Purpose: ...
```

ID areas by branch: `NAV` (00), `PROD` (01), `CONF` (02), `PROT[-TOPIC]` (03), `ATTACK[-TOPIC]` (04), `LAB` (05-lab), `API` (05-management-api), `FEAT` (06-feature-domain), `WF` (06-workflows), `GAP` (07), `PARAM` (08). Numbers aren't contiguous. Search existing IDs before you pick one.
